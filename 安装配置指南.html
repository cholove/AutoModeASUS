AutoModeASUS 新电脑安装配置步骤

华硕性能模式自动切换工具 · 部署指南

一前提条件检查

  1. 操作系统：Windows 10 (1903+) 或 Windows 11（自带 .NET Framework 4.8，无需额外安装运行时）
  2. 华硕机型：需已安装 ASUS 系统驱动（MyASUS 或 ATK Package），否则无法读写性能模式
  3. 验证驱动是否可用：拷贝过去后运行 AutoModeASUS.exe get，能返回“当前模式”即说明 WMI 通道正常

二拷贝文件

文件是否必需说明
AutoModeASUS.exe必需单文件即可运行，图标已内嵌
config.json可选保留个性化配置（空闲阈值 / 快速跳转规则）；不拷则首次运行自动生成默认值
stop.bat可选用于快速停止程序
log\ 目录不用拷，程序自动创建。

三安装步骤

:: 1. 把文件放到一个固定目录，例如
D:\Software\AutoModeASUS\

:: 2. 验证 WMI 通道（华硕机型必须成功）
AutoModeASUS.exe get

:: 3. 手动测试模式切换
AutoModeASUS.exe set silent    :: 安静
AutoModeASUS.exe set balanced  :: 标准
AutoModeASUS.exe set turbo     :: 性能

:: 4. 安装开机自启（写入当前用户的注册表 Run 键）
AutoModeASUS.exe --install

:: 5. 启动托盘后台程序
AutoModeASUS.exe

四验证功能

  1. 托盘图标：任务栏右下角出现风扇图标，颜色对应当前模式 绿=安静 橙=标准 红=性能
  2. 右键菜单：可手动切换三档模式，勾选状态实时同步
  3. 自动切换：停止操作 5 分钟后自动切标准（橙色），动鼠标恢复后自动切回性能（红色）
  4. Fn+F 手动切换：按键盘 Fn+F 后，程序会尊重手动选择并以该档为新偏好
  5. Ctrl+G 快速跳转（可选）：打开记事本的“打开/另存为”对话框，按 Ctrl+G 应跳转到资源管理器当前打开的文件夹

五常见问题

现象原因与处理
get 命令报错“读取失败”非华硕机型或未装 ATK/MyASUS 驱动，本程序无法使用
托盘图标一直是灰色WMI 初始化失败，查看 log\auto-mode.log 定位
Ctrl+G 对管理员权限对话框无效需右键 exe →“以管理员身份运行”（或设置快捷方式属性勾选）
提示“已有实例在运行”单实例保护，先运行 stop.bat 或任务管理器结束旧进程
开机没有自动启动重新执行 AutoModeASUS.exe --install，注意自启绑定的是当前路径，移动目录后需重装

六卸载

AutoModeASUS.exe --uninstall   :: 移除开机自启
:: 再直接删除整个目录即可
